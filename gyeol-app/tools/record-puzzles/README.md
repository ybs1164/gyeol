# 실제 기보에서 추출한 승리 퍼즐

2026-11-12부터 오늘의 퍼즐과 퍼즐 도전에 **검증된 실전 후반 84문제**를 사용합니다. 목표는 우세 만들기·역전·승리 굳히기입니다. 화면에 뒤집을 장수 목표를 주지 않으며, 정답은 상대의 최선 방어에도 실제로 승리하는 수입니다.

완료된 AI 대국 680판과 온라인 대국 10판, 총 690판에서 실제로 등장한 판을 추출했습니다. 후보 149개를 모두 독립 검증한 뒤, 한 수로 바로 끝나는 65개를 제외했습니다. 출제하는 84문제는 전부 상대 응수를 읽어야 합니다. 그중 22문제는 당장 가장 많이 뒤집는 수를 두면 승리할 수 없습니다.

| 목표 | 문제 수 |
|---|---:|
| 우세 만들기 | 10 |
| 역전 | 52 |
| 승리 굳히기 | 22 |

## 출처와 채택 기준

- 원본은 기존 facing 규칙 AI 평가 대전, 첫 수·두 수 실험의 완료 대전, 정상 종료된 실제 온라인 대국입니다. 초반 수를 지정한 실험은 그 초반 수와 회전·대칭 변환까지 재현합니다.
- Python 원본 규칙으로 모든 원본 대국의 합법성·수순·최종 승패·타일 차이를 확인했습니다. 기록에 저장된 중간 판과 궤적도 대조했습니다.
- 기보에서 실제로 둔 다음 수가 정답에 포함되고, 해당 플레이어가 실제 원본 대국에서도 이긴 경우만 채택했습니다.
- 모든 문제에 승리하는 수와 승리하지 못하는 수가 함께 있습니다. 의미 없는 전부 정답 국면과 회전·대칭 중복은 걸러냈습니다.
- 현재 수록 범위는 종국까지 정확하게 검사할 수 있는 20~23장 후반 국면입니다. 현재 타일 수에서 앞서 있는지만으로 유리하다고 판정하지 않습니다.
- 레이팅 보정 대전의 기존 승패 요약에는 수순이 없어 그 요약만으로 문제를 만들지 않았습니다. 임의의 판을 생성해 실전 출처로 표시하지 않습니다.

각 문제의 `source.gameId`, 원본 파일·대국 번호(`reference`), 원본 수순 위치(`ply`, `moveNumber`), 실제로 둔 수(`playedMove`)가 저장돼 있습니다. 원본 파일의 SHA-256과 완료 대국의 수순은 [원본 기보 스냅샷](source-games.json)에 보관했습니다. 온라인 사용자의 이름·인증 토큰은 포함하지 않습니다.

## 종국까지의 검증

1. 추출기는 실제 종국의 타일 차이만 평가하는 정확 탐색을 사용합니다. 깊이 제한에서 추정 점수를 반환하지 않습니다. 계산 한도를 넘긴 후보는 출제하지 않습니다.
2. 별도의 검증기는 알파베타 가지치기를 쓰지 않고 모든 합법 수를 끝까지 열거했습니다. **3,119,902개 상태**에서 후보 149개의 저장된 수별 결과, 정답 분기, 오답 응수, 원본 기보 위치를 검사했습니다.
3. Python 원본 facing 규칙과 **3,511개 풀이 국면·26,876개 전이**의 합법 수 목록, 다음 판, 종료 판정을 대조했습니다. 모두 일치했습니다.
4. 검증한 데이터와 원본의 해시가 일치할 때만 배포용 은행을 생성합니다. 실제 화면은 이 검증된 수별 결과만 사용하고, 상대는 종국 결과를 기준으로 가장 강한 방어를 둡니다. 승리하기 전에 풀이 깊이를 소진했다는 이유로 성공 처리하지 않습니다.

위 검사 숫자는 검증 후보 149개의 전체 범위이며, 실제 출제 84개는 그중 상대 응수가 필요한 부분집합입니다. 정답 판정에는 휴리스틱 승률이나 뒤집은 장수를 사용하지 않습니다.

## 난이도와 기록

8단계 경계는 기존 AI 기준점 974·1136·1313·1483·1622·1753·1954·2207점을 유지합니다. 각 단계에는 10~11문제를 배치했습니다. 문제 점수의 상대 순서는 남은 수, 합법 수 대비 정답 수, 탐색 작업량으로 추정합니다. **승리 가능성은 정확히 검증했고, 사람이 느끼는 난이도·정답률은 추정치**입니다.

기존 퍼즐 점수·최고점·전적·풀이 이력은 보존합니다. 이전 장수 목표 문제는 출제에서 제외하고, 풀던 문제 ID는 `retiredCurrent`와 `gyeol:puzzle-rating-v2-bank-backup`에 보관합니다. 기존 점수 척도 변환을 다시 적용하지 않습니다.

오늘의 실전 퍼즐은 `gyeol:record-daily-puzzles`에 별도로 저장합니다. 이전 날짜별 장수 풀이 기록은 원래 키에 보존하며, 연속 풀이 기록에도 반영합니다. 새 목표를 예전 정답 기록으로 완료 처리하지 않습니다. 풀기 시작한 오늘의 문제 ID는 고정해서 은행이 늘어나도 이어 풀 수 있게 했습니다.
