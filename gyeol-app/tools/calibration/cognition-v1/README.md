# 판단 시간 기반 AI 1,000명 · 60,000판 배치

2026-11-14 시작. 완료 결과는 `progress.json`, `report.json`에서 확인한다. 이 파일의 예정 수량을 완료 수량으로 해석하지 않는다.

## 구성

- 이전 1,000명의 ID·이름·순서를 보존했다. 프로필에서는 실수 추첨과 기준 봇 혼합을 사용하지 않는다.
- 브론즈~마스터의 6개 설계 기준 사이에 인식 지연, 가중치 증가 시간, 검토 폭·속도, 조기 착수 기준을 연속 보간했다. 1,000개 설정이 모두 다르다.
- 프로필의 `targetTier`는 설계 목표다. 실측 레이팅으로 표시되는 티어와 같다고 사전 보장하지 않는다.
- 기본 대국 50,000판: 1명당 선공 50판·후공 50판. 3분 모드로 개별 레이팅을 추정한다.
- 별도 검증 10,000판: 1명당 선공 10판·후공 10판. 1분 2,000판·3분 6,000판·5분 2,000판이다.
- 모든 상대 조합은 동일 시작 수순으로 선후공을 바꾼 두 판을 묶는다. 가까운 실력과 먼 실력의 대진을 함께 사용한다.
- 0/2/4/6수 시작 국면을 사용하고, 같은 상대·모드·시작 수순의 반복을 배제한다. 시작 수순 선택에만 난수를 사용한다. AI 착수는 결정적이다.

## 실행 방식

실제 ONNX 모델과 실제 규칙 엔진으로 둔다. 사고 시간의 기다림은 논리 시계로 대체하며 각 AI의 남은 대국 시계에서 차감한다. 단계가 열리기 전에는 모델을 호출하지 않고, 완료되지 않은 판단을 사용할 수 없다. 캐시 적중이나 빠른 PC로 논리 검토량이 늘어나지 않는다.

이 자료는 실제 온라인 서버의 동시 대국 용량이나 사람 상대 레이팅을 측정한 결과가 아니다. 시간패도 논리 시계 기준이며 운영 서버의 지연과 장애를 재현하지 않는다. 100판 기본 대국은 개별 추정의 출발점이며, 이웃한 1,000명의 미세한 실력 차이를 전부 증명하지 않는다.

배치는 별도 프로세스 6개로 실행한다. 창을 닫아도 계속되며, PC가 실행 중인 동안 진행한다. 완료 시 레이팅·검증 보고서를 자동 생성한다. 운영 `bot-ratings.json`은 자동 교체하지 않는다. 새 점수 반영 시 퍼즐 점수 척도와의 연계도 함께 갱신해야 한다.

## 확인·재개

프로젝트 루트 PowerShell에서 실행한다.

```powershell
# 현재 완료 수량, 속도, 남은 시간 추정
./tools/start_cognitive_batch.ps1 -Status

# 중단된 작업 재개. 실행 중이면 중복으로 시작하지 않는다.
./tools/start_cognitive_batch.ps1 -Workers 6

# 완료 자료 검증 및 보고서 재생성
npm run calibrate:cognitive -- --fit-only
```

`run.lock`과 PID로 중복 실행을 막고 한 판이 끝날 때마다 JSONL을 저장한다. 재개 시 저장된 대국의 합법 수순과 종국을 다시 검사한다. 모델·규칙·판단 코드·대진이 바뀌면 기존 원자료와 섞지 않고 실패한다. 해당 입력의 소스 스냅샷을 `source/`에 보관했다. 손상된 JSONL의 마지막 줄은 조용히 버리지 않고 검사 오류로 남긴다.

## 구현 검사

착수 엔진은 `packages/ai/src/cognition.ts`, 프로필은 `cognitive-persona.ts`, 예산은 `time-policy.ts`에 있다. `tools/calibrate_cognitive_bots.ts`가 대국과 보정을 실행한다. 기존 확률 엔진은 이전 보정 자료와 비교할 수 있도록 보존했으며 이번 배치에서 사용하지 않는다.

- 초기 구현 120판과 최종 판단 엔진의 혼합 모드 확인 48판을 별도 디렉터리에서 실행했다. 본 배치의 학습·검증 자료로 재사용하지 않았다.
- 전체 테스트 121개와 타입 검사 통과. 인식 전 모델 미사용, 결정적 선택, 시계 마감, 선후공 균형·중복, 서버에서 멈춘 추론의 마감 착수를 확인했다.
- 검증은 목표 프로필 순서의 넓은 구간 점수율과 선후공 한 쌍을 묶은 근사 하한을 보고한다. 모드별 표본 부족·실력 순서 역전이 있으면 `complete-review-required`로 남긴다.
- RD는 정보 행렬의 대각 근사이며 최소 60 Elo를 적용한다. 인접 순번의 정밀한 차이에 대한 확정적 오차 범위로 사용하지 않는다.
