# 넓은 실력 범위의 AI 1,000명

2026-11-15. 기존 표시 범위 974~2207에 맞춰 **실제 판단 능력도 함께 넓히는 별도 버전**이다. 점수를 늘려 쓴 것이 실력 차이의 증명은 아니므로 목표 점수와 측정 점수는 구분한다.

## 현재 배치

| 설계 목표 티어 | 목표 점수 | 인원 |
|---|---|---:|
| 브론즈 | 974~1300 미만 | 265 |
| 실버 | 1300~1500 미만 | 162 |
| 골드 | 1500~1600 미만 | 81 |
| 플래티넘 | 1600~1750 미만 | 121 |
| 다이아 | 1750~1900 미만 | 122 |
| 마스터 | 1900~2207 | 249 |

1,000명의 ID·이름·순서를 유지하고, 목표 점수 간격은 약 1.234점으로 배치했다. `roster.json`, `profiles.csv`의 `targetRating`은 설계·체험 매칭용 목표이며 실측 Elo가 아니다.

## 행동 차이

- 하위는 먼저 살펴본 일부 후보 중에서 판단하며, 판단 시간이 지나면 현재 결과로 착수한다. 낮은 단계가 후반에 시간이 남는다는 이유만으로 깊은 모델 판단에 쉽게 도달하던 현상을 제한한다.
- 상위는 인식 속도·후보 검토 폭·탐색량이 증가한다. 학습 단계에서는 초기 국소 후보의 제한을 풀고 전체 합법 수를 탐색한다.
- 최하위의 3분 기준 판단 창은 1.2초, 최상위는 최대 8초다. 모드·잔여 시간·실제 계산 마감이 이를 더 줄일 수 있다.
- 탐색 상한은 0~2048회로 분포한다. 시간과 단계별 비용 때문에 매번 이 상한을 모두 실행하는 것은 아니다.
- 실수 추첨, 매 수 기준 AI 추첨, 정책 확률에서의 착수 추첨을 사용하지 않는다. 같은 국면·개인 프로필·논리 시간에서는 같은 수를 선택한다.

하위의 후보 탐색 방향 편향, 상위의 계산 비용, 실제 점수 간격은 검증할 항목이다. 후보 제한과 학습 단계의 선택 방식을 함께 바꾼 것이므로, 어느 변화의 기여가 큰지 이번 대국만으로 분리해서 주장하지 않는다.

## 실행 순서

1. `anchor-check/`: 대표 프로필 7개를 기존 실측 기준 AI 8종과 비교하는 224판. 대표마다 32판, 선후공·시작 국면 균형.
2. 진행 중인 `cognition-v1` 60,000판도 그대로 완료해 비교 자료로 보관한다.
3. 두 작업이 완료되고 새 버전의 기준점 검증이 통과하면 `campaign.json`의 관리 프로세스가 새 버전 60,000판을 시작한다. 1,000명마다 기본 대국 100판·별도 검증 20판이다.
4. 기준점 검증이 실패하면 `review-required`로 종료한다. 이 경우 설정을 조정하고 새 실행 폴더로 검증해야 한다.

기준점 비교는 기존 974~2207 척도의 AI를 고정 기준으로 사용한다. 이 비교에서 기존 확률 엔진은 **상대 기준점에만** 사용하며 새 AI 1,000명에는 적용하지 않는다. 통과 기준은 224판 완료·대표마다 32판·양 끝 대표의 기준점 추정 간격 700 Elo 이상이다. 이 조건이 정확히 974~2207 전체를 실측 달성했다는 뜻은 아니다.

전체 새 대국의 `rating`은 일반 Bradley–Terry 측정 점수다. 각 프로필의 `targetRating`과 별도로 저장한다. 목표 범위에 맞추려고 대국 측정치나 승패 기록을 바꾸지 않는다.

## 확인과 체험

```powershell
# 기준점 대국 진행
Get-Content tools/calibration/cognition-v2-wide/anchor-check/progress.json

# 기존 대국 완료·기준점 검증을 기다리는 자동 실행 상태
Get-Content tools/calibration/cognition-v2-wide/campaign.json

# 작업이 중단됐을 때 각각 재개
npm run benchmark:cognitive-wide -- --workers 2
npm run campaign:cognitive-wide

# 새 AI 체험 서버
npm run play:cognitive-wide
```

체험 주소는 `http://localhost:8787/#/pvp`다. 3분 → 대국 시작으로 새 프로필과 대전한다. 체험 서버는 별도 데이터 파일 `packages/server/data/cognitive-wide-preview.json`을 사용한다. 표시·매칭에는 기존 범위의 목표 점수를 사용하며 운영 레이팅 파일은 검증 전에 교체하지 않는다.

관련 구현: `packages/ai/src/cognition-wide.ts`, `tools/calibrate_cognitive_bots_v2.ts`, `tools/benchmark_cognitive_wide.ts`, `tools/run_wide_campaign.ts`. 기존 `cognition-v1` 소스·모델·원자료는 그대로 보존했다.
