# 이전 임의 생성 퍼즐 난이도 기록 (출제 종료)

이 문서의 3,200문제는 현재 출제하지 않습니다. 새 문제와 검증 결과는 [실전 기보 퍼즐](../record-puzzles/README.md)에 있습니다. 아래 내용과 CSV는 이전 기록의 보존·변환을 위한 자료입니다.

AI 보정 결과의 기준점 974·1136·1313·1483·1622·1753·1954·2207점을 퍼즐 8단계에 반영했습니다. 최고 단계에는 2349점까지 마무리 문제를 배치했습니다. 문제의 복잡도 백분위를 이 척도에 펼친 **추정 난이도**이며, AI나 사람이 실제로 푼 정답률을 측정한 레이팅은 아닙니다.

| 단계 | 이름 | 점수 구간 | 문제 수 | 주요 종류 |
|---|---|---|---:|---|
| 1 | 입문 | 974~1135 | 400 | 작은 판에서 1~2장 뒤집기 |
| 2 | 초급 | 1136~1312 | 436 | 최다 뒤집기 |
| 3 | 중급 | 1313~1482 | 591 | 최다 뒤집기·응수 읽기 |

| 8 | 입신 | 2207~2349 | 138 | 마무리 |

기존 2,800문제의 ID와 판·목표를 유지하고 점수만 재배치했습니다. 추가 입문 400문제는 3~7장짜리 작은 판에서 시작하고 음수 시드 ID를 사용하므로 기존 기록과 충돌하지 않습니다. 총 3,200문제입니다. 모든 단계에 100문제 이상 있습니다.

## 추천과 첫 시작

- 퍼즐 기록이 없고 대국 배치 5판을 마쳤으면 대국 레이팅을 첫 퍼즐 점수의 참고값으로 사용합니다. 이후에는 퍼즐 성적을 독립적으로 반영합니다.
- 대국 배치 전이나 오프라인에서는 1000점부터 시작합니다. 풀던 문제나 기존 퍼즐 성적이 있으면 대국 점수로 덮어쓰지 않습니다.
- 자동 추천은 정답률 약 65%를 목표로 퍼즐 점수보다 약 108점 낮은 난이도를 중심으로 고릅니다. 실제 정답률을 보장하는 값은 아니며, 문제 은행의 양 끝에서는 가장 가까운 난이도를 씁니다.
- 단계를 직접 고르면 해당 단계의 점수 범위와 문제 종류를 지킵니다. 같은 단계의 문제를 모두 풀었을 때 다른 단계로 넘어가는 대신 연습 문제를 재출제합니다.
- 이미 푼 문제는 점수·전적에 다시 반영하지 않습니다. 저장 계층과 화면 모두 중복 반영을 막습니다.

## 기존 기록과 오늘의 퍼즐

이전 점수·최고점·그래프는 기존 단계 안에서의 상대적 위치를 보존해 새 척도로 한 번만 변환합니다. 풀이 수·정답 수·연속 정답·푼 문제 ID·진행 중인 문제를 보존합니다. 이전 값은 이 기기의 `gyeol:puzzle-rating-v1-backup`에 백업하고 새 기록에는 `scaleVersion: 2`를 남깁니다.

오늘의 퍼즐은 날짜별 판과 정답을 유지합니다. 문제 은행의 복잡도 곡선으로 계산한 추정 난이도·단계만 추가로 표시하므로 기존 날짜별 풀이 기록과 공유 결과를 사용할 수 있습니다.

## 재생성과 검증

```bash
npm run puzzles
npm test
npm run typecheck
npm run build
```

`npm run puzzles`는 서버의 AI 보정 결과에서 기준점만 추려 `packages/core/src/puzzle-scale.ts`를 갱신합니다. 브라우저에 AI 1,000명의 전체 데이터를 넣지 않습니다. 같은 입력으로 두 번 생성했을 때 문제 은행과 척도 파일이 바이트 단위로 일치함을 확인했습니다.

검증: 전체 52개 테스트, 타입 검사 통과. 기존 2,800개 ID 유지와 표본 70개의 판·목표 불변을 확인했습니다. 입문 400문제의 판 크기·정답, 단계별 출제 범위, 추천 목표, 이전 기록 변환의 중복 방지, 대국 점수로 첫 시작, 재풀이 점수 중복 방지를 검사했습니다.
