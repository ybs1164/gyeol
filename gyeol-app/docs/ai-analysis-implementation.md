# AI 복기 분석 구현 및 검증

2026-11-12. 웹 앱의 1차 분석 개선을 구현했다. APK 설치·배포와 외부 사이트 배포는 수행하지 않았다.

2026-11-13 후속 변경은 [승률·속도·가시성 실행 결과](win-probability-execution.md)에 기록했다. 아래 내용과 측정 수치는 이전 버전의 기록이다.

## 사용할 수 있는 기능

- 초·중반의 모든 합법 후보에 최소 탐색을 적용하고, 실제 착수와 유망 후보는 예산을 늘려 비교한다. 일반 분석은 후보별 12회에서 시작해 주요 후보를 48→96회로, 정밀 분석은 48회에서 시작해 192→384회로 확장한다. 추가 탐색은 기존 트리를 이어 쓴다.
- 후반은 남은 배치 5개 이하부터 정확 탐색을 시도한다. 국면별 100,000노드·350ms 한도 안에 전체 후보를 확인했을 때만 ‘종국까지 확인’으로 표시한다. 한도를 넘기면 추정 탐색으로 돌아간다.
- 최선수·훌륭한 수·좋은 수·무난한 수·부정확한 수·실수·큰 실수의 7단계를 표시한다. 안정성이 부족하면 잠정 등급을 표시하고 확정 판정과 집계는 보류한다. 강제수·강제 패스는 평가 통계에서 제외한다.
- 놓친 승리, 놓친 유일한 방어, 유일한 수 발견을 정확 탐색 결과로 판정한다. 초·중반의 기회 누락은 안정된 추정 평가에서만 표시한다.
- 그래프의 각 점은 같은 수 번호의 실제 보드를 나타낸다. 시작 국면도 평가하고, 기존 두 국면 이동평균과 시작값 50 고정을 제거했다. 색 관점 전환, 현재 값, 축 눈금, 주요 착수 표시, 포인터·키보드 선택을 지원한다.
- 실제 수와 추천 수를 별도로 선택하고 상대 응수까지 재생할 수 있다. 보드 중앙 정렬 이후에도 해당 수순의 실제 좌표를 사용한다.
- 대국 요약과 전체 수 목록, 내 수·주요 수 필터, 이전/다음 주요 수 이동을 제공한다.
- 분석 전용 워커로 대국 AI와 분리했다. 부분 결과·진행률을 표시하고 즉시 중지, 부분 재개, 오류 뒤 재시도를 지원한다. 기보 변경·화면 이탈 시 이전 워커를 종료한다.
- 분석은 원본 기보와 별도로 IndexedDB에 저장한다. 모델·규칙·엔진·등급·분석 모드·시작 국면·전체 수순으로 캐시를 구분한다. 최대 100개·24MiB 예산으로 오래된 캐시를 정리한다. 저장 실패로 원본 기보를 지우거나 분석을 중단하지 않는다.
- 기권·시간패는 대국 결과와 마지막 보드의 형세를 별도로 표시한다. 한국어·영어·일본어·중국어를 지원한다.

## 검증 결과

- `npm test`: 13개 테스트 파일, **67개 테스트 통과**.
- `npm run build`: 전체 타입 검사, 웹·PWA 빌드, 서버 번들 통과.
- 테스트에는 독립 전수 탐색과 모든 후반 후보 비교, 색 반전, 무승부, 강제 패스, 유일 방어, 불법 기보, 트리 재사용, 정확 탐색 취소·한도 초과, 부분 재개, 캐시 입력 구분과 손상된 자료 거부, 번역 키 검사가 포함된다.
- 실제 프로덕션 빌드를 격리한 Chrome의 390×900 화면에서 검사했다. 실제 ONNX 워커, 수순의 보드 좌표, 그래프 선택, 캐시 재열기, 정밀 분석, 취소·재개, 기보 변경, AI 파일 로딩 오류·재시도, 기권 기록, 불법 기록, 가로 넘침을 확인했다. 런타임 예외는 없었다.

### 실제 모델 비교

검증된 퍼즐 후보 중 22장 이상인 후반 **115국면, 후보 1,401개**를 사용했다. 같은 배포 모델에서 기존 한 수 신경망 평가의 승패 방향과 정확 탐색의 정답을 비교했다.

| 지표 | 기존 한 수 평가 | 신규 분석 |
|---|---:|---:|
| 후보 승패 방향 오류 | 455 / 1,401 | 0 / 1,401 |
| 전체 후보를 종국까지 확인한 국면 | 해당 없음 | 115 / 115 |

이 표본은 승리 기회가 있는 후반 퍼즐을 중심으로 선정되어 있다. 초·중반의 일반 대국 정확도나 확률 보정 성능을 대표하지 않는다. 기존 오류 수는 ‘이 수의 최종 승패 방향’에 대한 신경망 부호 오류이며, 실제 사용자의 실수 개수나 실수 탐지 오탐률은 아니다.

23수 고정 실전 기보 한 판의 일반 분석은 현재 PC의 Node/WASM에서 약 **41.8초**가 걸렸다. 모델과 캐시가 준비된 상태에서 최초 신경망 부분 결과는 4ms, 첫 착수 분석 완료는 약 1.95초였다. 전체 23수 중 정확 탐색 5수, 확정 등급 6수, 확정 보류 17수였다. 보류 수에도 현재 평가에 따른 잠정 등급은 표시한다.

한 판 측정이므로 p95 성능으로 표현하지 않는다. 모델 다운로드·콜드 로딩 시간과 Android 실기기 성능은 이 수치에 포함되지 않는다.

## 남은 후속 작업

현재 단일 value 모델의 값을 실제 승리 확률로 검증한 것은 아니다. 따라서 화면은 **AI 형세 평가**로 표시한다. 승·무·패 모델 학습과 고정 정책 대국을 이용한 확률 보정은 후속 범위로 남아 있다.

초·중반은 추정 탐색이며, 현재 예산에서 확정하지 못한 수가 많을 수 있다. 정밀 분석을 제공하지만 모든 수의 등급 확정을 보장하지 않는다. 계획의 고예산 초·중반 평가셋, 대국 단위 분할·신규 대국 일반화 검증, 예산 2배 시 등급 유지율 95% 검증은 아직 완료하지 않았다.

PC 15초·중급 Android 45초라는 원래 p95 목표도 충족했다고 주장하지 않는다. 현재 측정에서는 PC 한 판 41.8초였다. 진행률·부분 결과·취소·캐시를 제공하며, 추가 성능 개선과 실제 Android 측정이 필요하다.

## 재현

```powershell
npm test
npm run build
node --import tsx tools/bench_analysis.ts 200
```

```powershell
node --import tsx tools/check_analysis_ui.ts
```

Chrome 경로는 현재 Windows 환경의 `C:/Program Files/Google/Chrome/Application/chrome.exe`를 사용한다.
