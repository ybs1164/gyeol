# 수순 표기 구현

2026-11-13 수정. 문자열 열기·연습 화면과 배치·수순 복사 기능을 제거했다.

## 현재 화면

수순은 선공·후공 두 열로 나란히 표시한다. 각 플레이어가 자기 첫 수를 1로 세며, 패스도 한 수에 포함한다.

```text
선공        후공
1. D4u     1. D3U
2. D5d
```

- 한 수는 돌린 타일 좌표와 새 타일을 놓는 인접 방향이다.
- 방향은 `r/l/u/d`, 선공은 소문자, 후공은 대문자다.
- 목록에 팀 색 점·색 이름·뒤집은 장수를 표시하지 않는다.
- 행 높이는 24px이고, 목록 내부에서 스크롤한다.
- 기존 앱과 같은 글꼴·둥근 모서리·단색 아래 두께 띠·선택 배경을 사용한다. 격자선과 별도 고정폭 글꼴은 쓰지 않는다.
- 수를 선택하면 착수 직전 판을 확인하고 **수 두기**로 처리 후 판을 확인한다.
- 모바일 대국에서는 **수순 펼쳐 보기**를 이용한다.
- AI 분석 후에도 같은 두 열을 사용하고 평가를 작게 붙인다. 필터를 적용해도 원래 번호를 유지한다.

## 적용 범위

`components/GameLayout.tsx`의 공통 수순 표를 로컬·AI·온라인 대국과 복기에서 사용한다. 착수 확인 팝업은 `components/MovePreview.tsx`에 있다.

`screens/Notation.tsx`와 `components/NotationTools.tsx`를 삭제했고, 홈·내 정보·복기·대국의 관련 버튼과 앱 경로도 제거했다. 기존 기보와 규칙·서버 메시지는 변경하지 않는다. 공통 표기 변환기는 내부 데이터 처리를 위해 유지한다.

## 검증

- `npm test`: 16개 파일, 91개 테스트 통과.
- `npm run typecheck`, `npm run build -w @gyeol/web`: 통과.
- `npm run check:notation-ui`: 두 열과 독립 번호, 패스·후공 시작, 행 높이, 착수 전후 확인, 삭제한 UI·경로의 부재를 확인한다. 결과는 `tools/notation/ui-report.json`에 기록한다.
- `npm run check:analysis-ui`: 실제 AI 복기·평가 필터·추천 및 실제 수 재생을 확인한다.
