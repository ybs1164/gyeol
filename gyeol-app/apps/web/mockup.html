타일 3D 모델 활용

  • 로고·아이콘: 초록 타일 하나. 실제 모델(20×20×4mm, 홈 파인 제비꼬리 화살표)을 Blender Workbench "Flat"으로 렌더해 면마다 단색
  • 판 위 타일: 같은 모델의 화살표·테두리 홈 좌표를 그대로 SVG로 옮기고, 아래에 나무 옆면 띠(두께 비율 그대로)
  • 캐주얼 요소: 버튼·시간 모드·티어 배지·목록 아이콘도 타일처럼 아래 띠 하나. 눌리면 띠가 얇아지며 내려감
  • 렌더 스크립트: tools/render_tile_flat.py

온라인 시간 모드 · 흐름

  • 1분·3분·5분: 각자 한 판 전체 시간, 0이 되면 패배
  • 1일: 한 수에 24시간, 여러 판 동시 진행
  • 매칭은 같은 모드끼리. MVP는 레이팅·티어 하나를 모든 모드가 공유
  • 온보딩 = 로고 + 시작. 로그인은 MVP에서 게스트, Google 연결은 2차
  • 탭: 로비 · 내 정보 · 설정 (랭킹 탭은 MVP 제외)

v6 변경

  • 하단 탭: 내 정보 · 로비 · 설정 (로비가 가운데)
  • 로비: 온라인 대국 = 내 차례 데일리 대국(판 미리보기). 아래 고정 버튼은 "플레이"만
  • 플레이 화면: 1분·3분·5분·1일 선택 + 친구 초대·코드로 참가 → 매칭 시작
  • 모드 아이콘: 1분 불릿 = 총알, 3분 블리츠 = 번개, 5분 래피드 = 스톱워치, 1일 데일리 = 해. 플레이 카드·데일리 대국·기록 필터·기록 줄에 공통. 설정 탭은 해와 겹치지 않게 톱니바퀴로
  • 대국: 시계 왼쪽 타일 수 삭제
  • 대국 종료: 상대·나 정보 유지, 결과는 팝업(점수, 레이팅 변동, 한 판 더·복기)
  • 레이팅: 내 정보에서 분리한 별도 화면(현재·다음 티어·그래프·최고/최저·티어표)
