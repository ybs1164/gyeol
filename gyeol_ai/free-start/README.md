# Free-start 학습

빈 판에서 초기 타일을 직접 고르는 별도 학습 변형입니다.

1. 초록(선공)이 자기 타일의 방향을 선택합니다. 첫 타일은 중앙에 표시합니다. 좌표가 고정되지 않은 게임이므로 다른 위치에 놓는 것은 평행이동으로 같은 상태입니다.
2. 갈색(후공)이 자기 타일의 상대 위치와 방향을 선택합니다. 첫 타일에서 행·열 각각 -4~+4칸까지, 같은 칸을 제외한 80개 위치 × 4방향 = 320개 선택을 허용합니다. 전체 범위는 기존 규칙처럼 최대 5×5이며, 서로 인접하지 않아도 됩니다.
3. 두 번의 초기 배치에서는 회전·포획을 하지 않습니다. 이후 초록부터 기존 회전→놓기→포획 규칙으로 25장까지 진행합니다.

초기 배치 두 수도 MCTS 방문 분포와 최종 승패를 학습합니다. 초기 배치는 매번 고정하거나 무작위로 강제하지 않습니다. 자가대국의 탐험 과정에서 다양한 배치를 경험하지만 학습이 진행되면 일부 배치에 집중할 수 있습니다.

## 실행

프로젝트 루트에서:

```powershell
python free-start/main.py
```

또는 `free-start` 폴더에서 `python main.py`를 실행합니다. 기본값은 기존 학습과 같은 수당 탐색 100회·반복당 100국·실행당 약 5시간입니다. 시간 제한은 반복 경계에서 적용하므로 첫 반복이 길면 초과할 수 있습니다.

```powershell
python free-start/main.py --hours 2 --iterations 100 --games 100 --sims 100 --seed 20261020
```

결과는 실행 위치에 관계없이 **free-start/temp/**에 저장하고, 다시 실행하면 이 폴더의 모델과 리플레이를 이어서 학습합니다. 첫 실행은 새 모델로 시작합니다. 기존 루트의 `temp` 모델·학습 자료는 불러오지 않습니다. 배치 정책 출력이 추가되어 기존 모델과 체크포인트 형식이 다릅니다.

공통 Coach·MCTS·기존 게임 규칙·신경망 학습 코드는 상위 프로젝트에서 가져옵니다. 따라서 이 폴더만 다른 위치로 옮겨서는 실행할 수 없습니다. 의존성은 기존 프로젝트와 같습니다(`torch`, `numpy`, `tqdm`).

모델 교체 평가는 선후공을 바꾼 쌍으로 진행합니다. 쌍의 절반은 빈 판에서 시작해 배치 선택까지 평가하고, 나머지는 난수로 만든 두 타일 배치부터 평가합니다. 새 모델의 이전 모델 상대 승률(무승부 제외)이 55% 이상일 때 채택합니다.

## 오프닝별 유불리 검사

```powershell
python free-start/evaluate.py --openings 16 --games 16 --sims 100
```

회전·반사 중복을 제거한 전체 두 타일 배치 중 16개를 표본추출하고 배치마다 16국씩 둡니다. `--games`는 배치당 대국 수이며 8의 배수여야 합니다. 색 교환은 선공의 위치·방향을 바꾸므로 중복으로 제거하지 않습니다. 빈 판에서 배치를 고르는 능력 평가가 아니라, **주어진 두 타일 배치에서 선공이 정규 첫 수를 둘 때의 유불리**를 비교합니다.

평가 시작 시 모델을 고정하며 `evaluations/날짜-시간/`에 모델 사본, SHA-256, 배치별 승률·95% 구간·점수 차이, 모든 수순과 배치 그림이 있는 `REPORT.md`를 저장합니다. 기본 평가만도 256국이므로 시간이 걸립니다. 표본 대국 승률은 현재 AI의 결과이며 게임 이론적 우위나 필승 증명이 아닙니다. 많은 배치를 비교해 고른 극단값은 추가 실험으로 검증해야 합니다.

학습 중 `temp/opening_games.jsonl`에도 각 대국의 두 타일 배치, 대칭 정규화 키, 수순, 결과, 점수 차이, 랜덤 상대 여부를 기록합니다. 이 로그는 모델이 계속 바뀌고 선택한 배치의 빈도도 다르므로, 고정 모델 평가와 구분해야 합니다. `training_metrics.jsonl`의 선후공 승수는 이전 모델 상대 평가이며 같은 모델끼리의 선공 승률이 아닙니다.

## 검증

```powershell
python free-start/test_free_start.py
```

모든 1,280개 초기 선택 조합의 범위·소유권, 대칭 변환, 완주 대국, 작은 신경망으로 학습·평가·저장·재개를 검사합니다. 검증용 체크포인트는 임시 폴더에만 만듭니다.
