# 결(GYEOL) AlphaZero

facing 규칙에서 초기 타일 두 장을 직접 선택하는 학습·배치 비교는 [`facing-free-start`](facing-free-start/README.md)에 있습니다. `python facing-free-start/main.py`로 실행합니다.

## 과적합 진단과 학습 정책 (v2)

- 자가대국은 모든 수에서 MCTS 방문 분포를 정책 정답으로 저장합니다. 첫 7수는 그 분포에서 착수하고, 8수부터는 최대 방문 수 중 하나를 선택합니다.
- 모델 교체 평가는 매 반복 새로 생성한 서로 다른 2~8수 시작 국면 20개에서 각 모델의 선후공을 교환해 40판 진행합니다. 시작 수순과 생성 seed를 로그에 저장합니다. 무작위 합법 수로 생성한 국면이므로 실제 대국의 시작 분포와는 다를 수 있습니다.
- `validation_suite_v2.examples`는 반복마다 자가대국 3판과 랜덤 상대 대국 2판(상대 색을 교환)을 최대 100판까지 모읍니다. 이 대국들은 리플레이에 넣지 않습니다. 랜덤 상대 대국의 가치 정답은 해당 상대와의 실제 결과이며 최적 플레이의 승패를 뜻하지 않습니다.
- `training_metrics.jsonl`의 `schema_version: 2`는 새 정책 정답을 사용한 기록입니다. `training.train_before/after`는 동일한 최대 4,096개 학습 표본의 평가 모드 점수이고, `validation_before/after`는 이번 반복에서 보류한 판의 점수입니다. 배열 순서는 정책 손실, 가치 MSE, 승패 적중률입니다.
- 기존 `training.epochs.loss_pi/loss_v/accuracy` 필드는 호환성을 위해 유지하며 **검증 지표**입니다. 각 epoch의 `train_eval`은 동일한 학습 표본의 평가 점수, `train_batch_loss_*`는 dropout이 켜진 실제 학습 배치 평균입니다.
- `validation_suite`는 상대 종류별로 동일한 세트에 대한 이전 모델과 후보 모델의 점수를 함께 기록합니다. 세트가 늘어나는 동안에는 서로 다른 반복의 절대 점수보다 같은 기록 안의 두 모델을 비교하세요. 모델 채택은 다양한 시작 국면의 대국 승률로 결정합니다.
- 기존 모델과 리플레이, `fixed_validation.examples`는 유지합니다. 기존 고정 검증의 정책 정답은 예전 형식일 수 있으므로 새 검증 세트와 정책 손실을 직접 비교하지 마세요. 기존 리플레이는 최대 10번의 새 학습 반복에 걸쳐 교체됩니다.

`python main.py`로 다음 학습을 시작하면 적용됩니다. 이미 실행 중인 프로세스에는 자동 반영되지 않습니다. 검증 세트 생성과 진단 평가로 반복당 시간이 추가됩니다.

[alpha-zero-general](https://github.com/suragnair/alpha-zero-general) 구조(Game / MCTS / Coach / Arena / NeuralNet)에 결의 규칙을 그대로 넣은 학습 코드입니다.

## 실행

```bash
pip install torch numpy tqdm
python test_logic.py          # 규칙 검증
python main.py                # 학습 (체크포인트: ./temp/best.pth.tar)
python pit.py                 # 사람 vs AI
python pit.py --vs greedy -n 40   # AI 실력 측정
```

`python main.py` 한 번이 약 5시간(`timeLimitHours`) 학습하고 종료합니다. 다음 반복이 제한 시간을 넘길 것 같으면
새 반복을 시작하지 않으므로 실제로는 5시간보다 조금 일찍 끝납니다.
다시 실행하면 `./temp/best.pth.tar` 와 `trainExamples.examples` 를 불러와 이어서 학습합니다.
처음부터 다시 하려면 `temp` 폴더를 지우세요.

## 웹에서 AI 와 대국

```bash
python server.py      # → http://localhost:8000
```

`temp/best.pth.tar` 를 사용하며, 학습 중이라도 **새 게임**을 누를 때 최신 모델로 다시 불러옵니다.
색(선공/후공)과 AI 강도(MCTS 50/200/800회)를 고를 수 있습니다.

## 규칙 구현 (gyeol/GyeolLogic.py)

| 규칙 | 구현 |
|---|---|
| 초기 배치 | 초록 → / 갈색 ← 를 마주보게, 초록 선공 |
| 돌리기 | 상대 타일 1개를 기존과 **다른** 방향으로 |
| 놓기 | 돌린 타일의 상하좌우 빈 칸에, 4방향 중 하나로 |
| 5칸 제한 | 판 전체 범위가 가로·세로 5칸을 넘지 않음 (완성 시 5x5) |
| 먹기 | 놓은 타일이 바라보는 상대 타일부터 화살표를 따라감 → 시작 타일이 아닌 내 타일에 닿으면 경로의 상대 타일을 모두 뒤집음(방향 유지). 빈 칸·시작 타일·순환이면 실패 |
| 패스 | 돌리기+놓기를 할 수 없으면 패스 |
| 종료 | 25개가 모두 놓이면 많은 쪽 승리 (안전장치: 양쪽 모두 둘 수 없으면 그 시점 개수로 판정) |

판은 떠다니는 형태이므로 7x7 내부 보드에 매 수마다 중앙 정렬합니다.
수(action) = 돌릴 칸(49) × 새 방향(4) × 놓을 위치(4) × 놓을 방향(4) + 패스 = 3137.
회전·반전 8가지 대칭으로 학습 데이터를 8배로 늘립니다.

## 학습 시간 (이 PC, CPU 전용, 측정값)

| 항목 | 시간 |
|---|---|
| 자가대국 1판 (MCTS 100회) | 약 30초 |
| 자가대국 50판 / 반복 | 약 25분 |
| 신경망 학습 / 반복 | 초반 3~8분 → 데이터가 쌓이면(10반복분) 25~80분 |
| 이전 모델과 대결 20판 | 약 10분 |
| **반복 1회** | **초반 약 40분, 이후 1~2시간** |

5시간 실행 1회 ≈ 3~6회 반복입니다. 빠르게 하려면 `numMCTSSims`(100→50), `numEps`, `epochs` 를 줄이거나 GPU 를 쓰세요.
